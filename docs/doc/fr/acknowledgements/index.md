# Remerciements

PillMate utilise des technologies des plateformes Apple, notamment Swift, SwiftUI, SwiftData et les notifications locales.

PillMate utilise également Firebase Crashlytics pour les rapports de plantage et les diagnostics lorsque cette fonctionnalité est activée.
